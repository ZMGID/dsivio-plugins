# 将用户事实与导演方案分开

开始创作、换人物/产品/语言或改变交付要求时读。

## 写 Brief

记录目标、观众、必须准确的事实、禁用表达、输入路径、修改范围、交付形式，以及付费工作/执行账号/预算许可。没有信息时记录未知；只对真实会影响制作的选择提问。

- 保留用户原本要求，不把参考片偶然的字体、长度或机位升级成要求。
- 明确哪些人物、产品和声音是用户提供，哪些需要制作。
- 在付费转写或 build 前确认许可覆盖；“可以访问”不是“可以消费”。
- 目标或事实发生变化时改 Brief，不用新的 Treatment 悄悄覆盖用户约束。

## 写 Treatment

给出创意答案：开头如何抓住注意、观众在各段得到什么、人物以何种态度交流、画面关系如何解释论点、声音如何交接。每个镜头说明用途，不只堆审美词。

正式台词只在 Source 内的 Script 维护；Treatment 可指向段落，不复制一整套台词。第 3 阶段 Script 语法使用前核对 vocabulary，不能把笔记中的时间标注直接当作者接口。

## 改编要改真实关系

换人检查人物全部表现与声音；换产品检查名称、功能、手持关系、视觉证据和论点；换语言检查自然表达、真实时长与表演，不只替换字面文本。保留参考发挥的作用，但让目标作品自己决定镜头长度和节奏。

# 用文件保持制作记忆

开始工程、恢复会话、整理或交接时读。文件名是建议，职责必须保持单一。

| 文件 | 保存什么 | 不保存什么 |
|---|---|---|
| notes/brief.md | 用户目标、事实、限制、交付、费用授权 | 导演擅自升级的要求 |
| notes/treatment.md | 创意方案、视听关系、镜头作用 | 正式台词完整副本 |
| notes/analysis.md | 对参考整体的观察与解释 | 将推论冒充事实 |
| notes/reference-timeline.md | 源片时间范围、对象状态、语音与帧证据 | 目标片强制沿用的秒数 |
| notes/progress.md | 当前问题、下一行动、阻碍、活跃 Build/task、复用入口、剩余预算说明 | 无限追加日志或可执行 Candidate 的替代品 |
| authors/*.dvml | 内容、依赖、生成与制作声明 | 本轮选择的隐藏状态 |
| recipes/*.dvs | Recipe 数据或文本模板 | 凭据与服务路由 |
| runs/*.dvrun | 本次 Target/Candidate/satisfy | 仅口头决定的复用 |
| .dsivio-video/ | 资源、运行与结果证据 | 可随手删掉的普通临时文件 |

## 恢复顺序

1. 确认 cwd/项目根与当前 Brief；不要误入工具安装目录。
2. 读 Treatment、Analysis、Progress，检查证据路径仍有效。
3. 读 Source/Recipe/所选 Run，确定剩余依赖。
4. 查询活跃 Build 的 status/inspect；有不确定付费请求先处理它。
5. 通过 history 找到可复用 Output，把选择写进 Run 后 plan。

## 交接检查

- [ ] 已选实际输出已导出且观看、聆听。
- [ ] 作者文件、相对导入、素材和必要历史资源绑定可用。
- [ ] 说明用户目标、当前创意、未解决问题及已许可的付费范围。
- [ ] 记录已检查的文件与范围；没有 Studio 可编辑入口时不捏造链接。

只交 MP4 是编码文件交付，不是可编辑项目交接。不要拿旧最终 Output 满足改过的下游制作，掩盖源编辑未生效。

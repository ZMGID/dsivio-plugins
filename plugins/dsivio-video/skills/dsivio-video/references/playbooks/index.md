# 按创作形态与局部工艺选择 Playbook

Format 是作品组织方式，Craft 是局部导演问题；可以组合，不是新的 DVML 类型。接口继续读 production 的组件专页。无参考也能制作，无付费生成也能交付。

## Format

| 当前委托 | 阅读 |
|---|---|
| 保留参考的结构/节奏，换主题或素材 | [参考改编](formats/reference-video-clone.md) |
| 对镜口播、提问与答案揭示 | [口播 / 采访](formats/talking-head-interview.md) |
| 产品证据、卖点与行动指引 | [产品宣传](formats/product-promo.md) |
| 累计比较结果、等级或前三名 | [排名视频](formats/ranking-video.md) |
| 双人关系与互补机位 | [播客](formats/podcast.md) |
| 旁白 / 人物统领解释性图形 | [讲解](formats/explainer.md) |

## Craft

| 当前问题 | 阅读 |
|---|---|
| 准确文字、Cue 阅读与测量高亮 | [字幕](craft/captions.md) |
| 对象变化、交接与画面层级 | [运动与层级](craft/motion-and-layering.md) |
| 原声、音乐与效果的主次 | [声音混音](craft/sound-mix.md) |
| 静图身份、场景、机位与参考分工 | [图像导演](../generation/image-direction.md) |
| 镜头内表演、动作与时长 | [视频导演](../generation/video-direction.md) |
| 模型支持和具体请求参数 | [模型目录](../generation/models.md)、[Surface](../generation/surfaces.md) |

从最相关的一页开始；不要把格式模板当硬性轨道数量、生成数量或预算。制作纯动画先运行 [本地示例](../production/examples/README.md)，有声音的作品仍必须听实际交付文件。

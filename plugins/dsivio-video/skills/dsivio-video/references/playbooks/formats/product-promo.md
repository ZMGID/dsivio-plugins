# 产品宣传与演示

## 何时使用

观众需要识别产品、看到真实好处和行动结果时读。

本页是制作决策，不声明新的作者元素；准确属性读 [制作参考](../../production/tracks.md)。不同格式可以组合。

## 1. 将主张和证据配对

Brief 保存准确型号/卖点/禁用说法，Treatment 为每个主张安排可见证据。规格、价格、CTA 用 typography；生成画面不能自动证明产品实测性能。

## 2. 资产图与动图分开

media:Image/Video 导入供应素材。静态校正用 image-transform，合成用 image-compose；图中准确文字仍保留作者工程。需要透明主体则使用预抠媒体，不请求不存在的去背景模块。

## 3. 让对象持续而非乱飞

media-track Item 展示单物，Sequence + Member + Handoff 做有意义替换，或 deck-track DepthStack 维持产品卡片历史。先看全画布注意顺序，再决定 enter/exit；读清前不离场。screen-overlay 只作有限强调。

## 4. 声音与交付

有真实旁白则 Normalize/Take→sound；已有音乐用 audio-track，gain/fades 明确，不自动 ducking。check/plan 审查素材来源与付费生成，build/get 后检查产品身份、标题可读性和发布画幅。

## 门禁与常见偏差

没有旁白也可以做纯本地宣传卡；不要为“AI”标签强加付费生成。

最终仍执行 check → plan →（实际 paid 请求先审批）→ build --follow → get；记录 Build ID、文件与真正看过/听过的范围。未知结果先 status，不新建付费 Build 重试。

# 导演一幅有用的图像

每次写或继承图像 prompt 前读，同时读 [model-families](model-families.md) 中所选家族。参数能力归 models，不把导演建议当解析器限制。

## 先决定画面的任务

说明这幅图是人物身份锚、产品事实、场景建立、视频首帧还是独立展示素材。一个请求生成一个完整画面；人物、产品、机位的依赖不是影片播放顺序。

| 关系 | 写清什么 |
|---|---|
| 主体 | 少量能辨认的特征、姿态、眼神与态度；不要几十个相互抵消的外貌词 |
| 场景 | 主体确实生活在怎样的环境；前后景与尺度提供何种信息 |
| 机位 | 景别、镜头高度、观察方向、视觉重点、留给后期文字的空间 |
| 光与材质 | 光从哪里来、轮廓怎样可读、关键产品材质如何保持 |
| 参考 | 哪个输入拥有身份/产品/空间事实，哪些特征应保留，哪些允许改 |

## 写具体的摄影意图

> 小工作室的晨间桌面。一位短发陶艺师侧坐，手扶一只青色陶杯，轻松看向画面右侧。中近景，相机与眼睛同高，左侧窗光照亮脸与杯口；桌面有少量真实工具，背景可辨认但不抢注意。杯子的形状与釉色遵循产品参考，不新增标识。人物放在画面左半，右半保留干净的桌面区域。

示例不是人物模板。准确尺寸、比例放请求属性，不在 prompt 中许诺模型必定遵守；生成后 probe/观看实际输出。精确标题、数字、品牌标签留后期制作，别拿模型绘出的错字当真实产品证据。

## 为连续镜头建立浅依赖

先接受一个身份与产品关系正确的主视图，再派生确有用途的另一角度。只传新画面需要的参考；别把所有历史生成加入下一请求。换人/产品时逐项检查手持、尺度、倒影和遮挡，不只看脸是否像。

## 验收后才继续生成

- [ ] 人物态度与作品一致，产品事实准确。
- [ ] 关键身体/物体关系可信，手、杯口、接触与阴影可见。
- [ ] 机位、焦点、光线与后期空间确实有用。
- [ ] 真实画幅与清晰度符合需要，不因请求成功就跳过检查。

失败先修负责的方向或参考关系，用最小小样验证；不要自动升级所有参数或批量重抽。
